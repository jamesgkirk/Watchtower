# assets/

This directory holds all static media for the Watchtower Records website.

## Current files

| File | Usage |
|------|-------|
| `watchtower-logo.svg` | **Primary logo** — used in nav, hero, and as favicon. This SVG contains the logo pre-processed for dark backgrounds (white chess piece, white text, white frame, transparent background). No CSS filter needed. |
| `watchtower-logo.jpg` | Original JPEG source (kept as backup). No longer referenced by the site. |

## Adding future assets

Place artwork, press photos, and any other media here before referencing them in
`index.html`, `style.css`, or `main.js`. Keep filenames lowercase and
hyphen-separated (e.g. `artist-photo-2026.jpg`).

For additional pages (Roster, etc.) that reference artist artwork, this
directory is the intended home for those images.
